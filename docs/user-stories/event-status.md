# Event status and arrangements

## User Story

As an Event Organiser, I want to view the current status and arrangements of my event so that I know what has been confirmed and what still requires attention.

## Acceptance Criteria

Ensure that the Event Organiser can:
- View the recorded status of their event.
- View the event's recorded details, including:
  - Date and time
  - Expected attendance
  - Venue
  - Room layout
  - Programme or session information
- View the status of venue booking and technical support arrangements as Pending, Confirmed, Rejected, or Unavailable, where applicable.
- View any venue or technical support arrangements that are still outstanding before the event can be confirmed.
- View event details that reflect any approved change or rescheduling.
- Be denied access when attempting to view an event they are not authorised to access, with the event details not displayed.
