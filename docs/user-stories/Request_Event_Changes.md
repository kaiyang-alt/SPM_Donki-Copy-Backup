# Request Event Changes

## User Story

As an Event Organiser, I want to request changes to my event so that I can keep
the event arrangements aligned with my latest requirements.

## Acceptance Criteria

Ensure that the Event Organiser can:

- Select an event they are authorised to manage when creating a change request.
- Request changes to relevant event details, including:
  - Date or time
  - Expected attendance
  - Programme or session timings
  - Venue requirements
  - Equipment requirements
  - Technical support requirements
- Provide details explaining the requested change.
- Review the requested changes before submission.
- Submit the change request once the change details have been provided.
- Receive confirmation that the change request has been successfully submitted.
- View the submitted change request with the status `pending`.
