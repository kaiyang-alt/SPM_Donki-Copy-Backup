# UML

This folder stores UML diagrams used to support ConnectSphere user-story implementation.

Use just-enough UML only when it helps clarify the design, structure or interaction for a user story.

Suitable diagrams include:

- Sequence diagrams for interactions, workflow and alternative flows
- Class diagrams where code-level structure needs clarification

Prefer PlantUML or Mermaid source so diagrams remain editable and version-controlled.

Each UML diagram should relate to a specific user story or implementation need.

Do not create unnecessary diagrams for unrelated parts of the system.

If a user-story document refers to a UML diagram, store the diagram here and reference its file path from the story document.
