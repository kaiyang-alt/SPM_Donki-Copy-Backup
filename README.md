# ConnectSphere Event Management System

IS212 Software Project Management  
AY 2026/27 Term 1

## Project Overview

ConnectSphere is an event management system developed as part of the IS212 Software Project Management course.

The system supports the end-to-end planning and management of events, including:

- Event request creation and approval
- Venue search and booking
- Equipment management
- Attendee registration
- Event change requests
- Notifications

## User Roles

The system supports five main user roles:

1. Event Organiser
2. Event Coordinator
3. Venue Staff
4. Technical Support Staff
5. Attendee
